## 🚢 Deploying to Vercel (Free & Instant)

### Option A: Via GitHub (Recommended)
1. Push this folder to a new GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: AI Engineer Portfolio"
   git branch -M main
   git remote add origin https://github.com/Bithal98/portfolio.git
   git push -u origin main
   ```
2. Log in to [vercel.com](https://vercel.com) using your GitHub account.
3. Click **"Add New Project"** and import the `portfolio` repository.
4. Click **Deploy**. Vercel will detect Vite + React and deploy your live URL (e.g., `https://bithal-sahoo.vercel.app`) in under 60 seconds!

### Option B: Via Vercel CLI
```bash
npx vercel
```
Follow the interactive prompts to deploy directly from your terminal.
